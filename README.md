# Omen Vault

A private, end-to-end encrypted vault app built with Flutter and Firebase.

- App ID: `com.belmontbennett.vault` (Android application ID and iOS/macOS bundle ID)
- Default branch: `develop-v3`
- Platforms: Android and iOS first; desktop builds are kept compiling. The web build shows a notice, because the encrypted local database isn't available in browsers.

## Development

```
flutter pub get
flutter analyze
flutter test
flutter run
```

Every push and pull request to `develop-v3` runs `flutter analyze` and `flutter test` in GitHub Actions.

### Feature flags

Elite5 features are built behind compile-time flags, all off by default (`lib/core/feature_flags.dart`). Turn one on for a local build with, for example:

```
flutter run --dart-define=FF_ELITE_LOCK=true
```

## Firebase

Firebase config for each platform is generated by the FlutterFire CLI (`flutterfire configure`). Security rules live in `firestore.rules`, `storage.rules` and `database.rules.json`, and are deployed with:

```
firebase deploy --only firestore:rules,storage,database
```
